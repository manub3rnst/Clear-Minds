Pendências que exigem ação

Dados sensíveis protegidos. O Clear Minds lida com informações de saúde mental. Por isso este painel mostra apenas contagens e status: diários, anotações e conteúdo privado de usuários não são acessíveis pela administração, e não há nenhuma rota que os devolva.

Quando uma informação sensível for estritamente necessária para uma função administrativa legítima, o acesso é feito caso a caso e a ação fica registrada na auditoria.

Regras da comunidade

Importar dados do navegador

As páginas do app ainda guardam tudo em localStorage. Esta ferramenta lê essas chaves e grava no banco do painel, para as telas de usuários, comunidade, consultas e financeiro deixarem de estar vazias.

Diário, humor, sono, ansiedade, pacientes e solicitações de diário são recusados na importação. O painel administrativo nunca recebe esse tipo de conteúdo.

O botão direto só enxerga os dados guardados nesta mesma origem (http://127.0.0.1:4173). Se você usa o app abrindo os arquivos .html pelo duplo clique, o armazenamento é outro: nesse caso use o arquivo .json ou o campo acima.
