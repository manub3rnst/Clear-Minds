# Diretrizes do Clear Minds

## Projeto

- O projeto utiliza HTML, CSS e JavaScript. Evite adicionar frameworks, bibliotecas ou outras tecnologias sem necessidade.
- Preserve as funcionalidades existentes. Não recrie o site do zero nem apague funções, páginas, IDs, classes ou comportamentos que ainda estejam em uso.
- Preserve o menu lateral atual; não o substitua nem crie um cabeçalho superior para a Home.
- Mantenha a identidade visual azul do Clear Minds. Imagens de referência orientam a estrutura, não substituem a identidade visual do projeto.
- A Home deve continuar responsiva em desktop, tablet e celular.
- Limite alterações às páginas e componentes necessários para a tarefa.
- Escopo de CSS específico à página ou componente sempre que possível para evitar impactos em outras páginas.

## Execução por etapas

- Cada etapa será enviada separadamente. Ao receber uma etapa, execute somente o que ela solicita; não antecipe etapas futuras.
- Antes de modificar qualquer coisa, analise o código atual relacionado à alteração e reutilize a estrutura e as funcionalidades existentes sempre que possível.

## PRDs

Os PRDs devem ser *sempre* criados na raiz do projeto atual, seguindo o formato `docs/plans/{{YYYY-MM-DD}}-{{descrição}}.md`.
